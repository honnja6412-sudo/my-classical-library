My Classical Library v1.2 AV — Webアプリ配置用パッケージ

1. このフォルダ内の5ファイルを、HTTPSで公開できる静的Webホスティングの同一フォルダにアップロードします。
2. 公開URLの /index.html をWindowsとAndroidで開きます。
3. Android Chromeのメニューから「ホーム画面に追加」または「アプリをインストール」を選択します（表示は環境によって異なります）。
4. 各端末で「バックアップ」からJSONを読み込んでください。

重要：
・このパッケージ自体をGoogleドライブに置いてもWebアプリの公開URLにはなりません。
・この版にログイン機能、クラウド保存、自動同期はありません。所有データは各ブラウザのローカルストレージに保存されます。
・Web公開版の保存先は、これまでのcontent://で開いた版と別です。公開版でJSONを読み込み直してください。
・公開先のURLを変更すると保存先も変わる場合があります。バックアップを定期的に保存してください。
・画像を多数保存すると容量制限に達する場合があります。大規模登録向けIndexedDBへの移行は今後の課題です。
・第三者にデータを見せたくない場合は、バックアップJSONを公開フォルダにアップロードしないでください。JSONは端末から読み込むだけです。
・ネットがない時は、HTTPS公開版を一度オンラインで開いてキャッシュできている場合にアプリ本体が起動します。外部検索やオンライン画像は利用できません。
